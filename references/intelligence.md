# 赛前情报采集规范 — 战术对位维度

## 概述

本文件定义 Agent 在采集赛前情报时需关注的**战术对位（tactical matchup）**维度。战术情报是 `intelligence.json` 中 `matches[].tactical` 字段的扩展，与伤停/状态等传统情报正交叠加。

战术情报**必须基于赛前分析或历史交锋数据**，不得凭空猜测。

---

## 一、战术风格枚举

每种队适用且仅适用一个主要风格（`style_a` / `style_b`），仅在球队无明显单一风格时使用 `hybrid`。

| 枚举值 | 中文名 | 特征描述 | 识别方法 |
|--------|--------|---------|---------|
| `high_press` | 高位逼抢 | 前场高强度压迫，迫使对手后场失误；防线压上，侵略性防守 | 场均抢断/拦截率高、对手场均传球成功率低、前场30米区域夺回球权数高 |
| `possession` | 传控 | 控球主导，短传渗透，耐心组织，通过传导撕开防线 | 场均控球率 >58%、传球成功率 >85%、场均长传次数少 |
| `counter_attack` | 防守反击 | 收缩防守，快速转换，利用对手压上后的空间 | 控球率低 (40-48%)、场均反击次数多、纵向传球比例高 |
| `direct` | 长传冲吊 | 快速通过中场，长传直接找前锋，争抢第二落点 | 场均长传 >60次、传球成功率 <75%、定位球进球比例高 |
| `defensive_deep` | 深度防守/大巴 | 全员退守，压缩空间，放弃控球权，专注禁区保护 | 控球率 <40%、防线极深、场均被射门数多但预期失球低 |
| `physical` | 身体对抗型 | 强调身体对抗、定位球、空中球优势，大量犯规和中断 | 场均犯规多、身高/体重优势明显、定位球进球占比高、空中对抗成功率 >55% |
| `hybrid` | 混合型 | 无明显单一风格，根据对手灵活调整 | 无稳定风格特征，场均控球率在48-55%之间波动 |

### 风格判断优先级

1. **本场比赛赛前报道**（最优先）：确认本场实际阵型/部署，如"预计首发4-4-2"、"主帅赛前表示会收缩防守"
2. **球队常规风格**：赛季统计数据（控球率、抢断率等），作为基线参考
3. **历史交锋记录**：对阵同类型球队时的战术选择
4. **客场比赛调整**：客场可能更保守，需考虑主客场差异

### 状态崩盘球队的特殊处理

当球队近期战绩很差（近5轮仅拿0-4分、连败3+场），必须主动考虑该队**放弃常规打法**的可能性：

| 场景 | 推测变阵方向 | 依据 |
|------|-------------|------|
| 客场崩盘队 vs 强队 | 改打防反/大巴 (`counter_attack` / `defensive_deep`) | 客场无胜算，死守求一分 |
| 客场崩盘队 vs 弱队 | 可能仍然常规打法但更谨慎 | 必须拿分但怕输 |
| 主场崩盘队 vs 强队 | 可能收缩防反，也可能破釜沉舟 | 视主帅性格而定 |
| 主场崩盘队 vs 同档/弱队 | 大概率加强进攻 | 主场必须止颓 |
| 多轮不胜+零进球 | 锋线调整，中后场收缩 | 进攻信心崩溃 |
| 多轮不胜+场均丢2+球 | 防线收缩，减少前压 | 防守必须优先 |

**处理规则**：
- **必须**搜索本场比赛赛前报道确认实际部署
- 如果搜不到确认信息，**默认按"推测变阵方向"赋值**，并在 `factors[]` 中注明"推测"
- `expected_pattern` 相应调整为 `"cautious"`（崩盘队保守是大概率事件）
- 如果推测弱队改打防反，且对手是传控/高压风格，**不需要过度惩罚**——崩盘队的防反执行力可能不足

## 二、战术克制矩阵

以下克制关系基于足球战术原理，幅度范围为 ±0.10~0.25 xG：

| 风格A | 风格B | 效果 | 幅度 |
|-------|-------|------|------|
| `high_press` | `possession` | 高位逼抢破坏传控出球体系 | +0.20 / -0.20 |
| `high_press` | `defensive_deep` | 高位逼抢难破大巴，被反击打身后 | -0.15 / +0.15 |
| `possession` | `defensive_deep` | 传控可缓慢渗透大巴，耐心寻找空档 | +0.15 / -0.15 |
| `possession` | `counter_attack` | 传控惧怕反击速度，一旦丢失球权即被快速打击 | -0.20 / +0.20 |
| `counter_attack` | `high_press` | 反击最擅长利用高位逼抢留下的空间 | +0.25 / -0.25 |
| `counter_attack` | `possession` | 反击克制传控，断球后直击空档 | +0.20 / -0.20 |
| `counter_attack` | `defensive_deep` | 反击面对深度防守难以找到空间 | -0.10 / +0.10 |
| `direct` | `possession` | 长传可绕过传控型中场，直接威胁防线 | +0.15 / -0.15 |
| `direct` | `defensive_deep` | 长传难破密集防守，缺乏渗透手段 | -0.10 / +0.10 |
| `direct` | `high_press` | 长传可破解高位逼抢，越过压迫层 | +0.10 / -0.10 |
| `physical` | `possession` | 身体对抗破坏传控节奏，利用定位球机会 | +0.15 / -0.15 |
| `physical` | `counter_attack` | 身体队阵型偏松散，容易被速度型反击打穿 | -0.08 / +0.08 |
| `physical` | `high_press` | 身体队出球精度低，面对逼抢失误多 | -0.10 / +0.10 |
| `defensive_deep` | `high_press` | 大巴可抵御高位逼抢，压缩身后空间 | +0.10 / -0.10 |

**注意**：
- 混合型（`hybrid`）风格对阵任何风格时克制效果减半（×0.5）
- 表中未列出的组合视为无明显克制关系（±0.00）
- 克制矩阵叠加开放性、无效控球等其他因子

## 三、采集来源要求

Agent 采集战术情报时**必须**在 `factors[]` 或 `notes[]` 中注明来源：

| 来源类型 | 可靠性 | 示例 |
|---------|--------|------|
| 赛前发布会主帅言论 | 高 | "主帅表示本场将采用高位逼抢应对对手传控体系" |
| 媒体赛前分析 | 中高 | "VG分析认为博德闪耀的高位逼抢将压制莫尔德的出球" |
| 历史交锋数据 | 中 | "首回合博德闪耀3-1胜，高位逼抢造成莫尔德3次后场失误丢球" |
| 本赛季统计数据 | 中 | "莫尔德场均控球率62%，但面对高位逼抢球队场均1.2次致命失误" |
| 阵容/阵型推断 | 中低 | "客队排出三中卫体系，可能意在加强防守反击" |

**禁止**：
- A：凭空猜测战术风格（"可能打防反吧"）— 需有依据（赛前报道/统计数据/崩盘状态）
- B：使用过时的风格判断（上赛季的数据不代表本赛季）
- C：过度消费克制关系（不是每次风格克制都产生显著效果）

**允许的推测**（在 `factors[]` 中必须注明"推测"）：
- **状态崩盘球队变阵**：当球队近5轮≤4分或连败3+场时，可以合理推测其放弃常规打法改打防反/大巴
- **客场保守**：客场对强队时，推测客队会更保守（`expected_pattern` 调整为 `"cautious"` 并提供依据）
- **主帅换人推测**：新帅上任、连败后更换阵容的合理推测

## 四、战术字段完整 JSON Schema

以下为 `intelligence.json` 中 `matches[].tactical` 字段的完整 Schema：

```json
{
  "matches": [
    {
      "teams": ["BOD", "MOL"],
      "tactical": {
        "style_a": "high_press",
        "style_b": "possession",
        "matchup": "高位逼抢克制传控出球体系",
        "expected_pattern": "open",
        "ineffective_possession": {
          "team": "B",
          "possession_pct": 78
        },
        "physical_mismatch": 1,
        "derby_boost": false,
        "fighting_spirit": {
          "a": {"level": "high", "note": "争冠冲刺，主场必须取胜"},
          "b": {"level": "normal"}
        },
        "counter_strategy": true,
        "underdog_boost": 0.06,
        "favorite_penalty": -0.05,
        "description": "博德闪耀高位逼抢破坏莫尔德出球体系"
      },
      "factors": [
        {"summary": "博德闪耀本赛季场均抢断18.3次，联赛第一"},
        {"summary": "莫尔德面对高位逼抢球队场均失误1.5次"}
      ],
      "notes": [
        "博德闪耀主帅赛前确认将延续高位逼抢策略",
        "莫尔德主力后腰伤缺，出球能力下降"
      ]
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 必填 | 取值范围 | 说明 |
|------|------|------|---------|------|
| `style_a` | string | 是 | 见风格枚举 | 主队（对阵中第一队）的战术风格 |
| `style_b` | string | 是 | 见风格枚举 | 客队（对阵中第二队）的战术风格 |
| `matchup` | string | 否 | 自由文本 | 克制关系简述 |
| `expected_pattern` | string | 否 | `open` / `cautious` / `balanced` | 对攻/保守预期，默认 `balanced` |
| `ineffective_possession` | bool/object | 否 | `false` 或 `{"team":"A"/"B", "possession_pct": int}` | 传控队是否面对大巴导致无效控球 |
| `physical_mismatch` | int | 否 | -2 ~ 2 | 身体对抗差异：2=主队明显优势, -2=客队明显优势, 0=均衡 |
| `derby_boost` | bool | 否 | `true` / `false` | 是否德比/特殊战意 |
| `fighting_spirit` | object | 否 | 见下方"战意等级" | 按队显式标注战意（A=主队，B=客队），预测中权重最高的人为因子 |
| `counter_strategy` | bool | 否 | `true` / `false` | 弱队是否有明显战术克制 |
| `underdog_boost` | float | 否 | 0.00 ~ 0.12 | 弱队 xG 加成（仅 `counter_strategy=true` 时生效） |
| `favorite_penalty` | float | 否 | -0.12 ~ 0.00 | 强队 xG 惩罚（仅 `counter_strategy=true` 时生效） |
| `description` | string | 否 | 自由文本 | 战术描述 |

### 各字段量化规则

| 因子 | 影响幅度 | 触发条件 |
|------|---------|---------|
| 战术克制 | ±0.08~0.25 xG | 两队风格存在明确克制关系（查克制矩阵） |
| 对攻/保守 | ±0.15~0.20 xG | `expected_pattern` 为 `open` 或 `cautious` |
| 无效控球惩罚 | -0.15~0.35 xG | 传控/混合型队面对深度防守或反击型队 |
| 身体对抗 | ±0.08~0.24 xG | `physical_mismatch` 非 0，每级 ±0.12 xG |
| 德比战意 | +0.15~0.26 xG | `derby_boost=true`，主队 +0.18，客队 +0.08 |
| 战意因素 | 每队 ±0.15~0.30 xG | `fighting_spirit` 按队标注，预测中权重最高的人为因子 |
| 总修正上限 | ±0.35 xG | 软截断：超过 ±0.25 部分对数衰减 |

### 战意等级（fighting_spirit）

`fighting_spirit` 结构：`{"a": {...}, "b": {...}}`（A=主队/对阵第一队，B=客队/对阵第二队），每队可写 `{"level": "...", "note": "理由"}` 或简写字符串 `"high"`。

| level | 中文 | 典型情境 | xG 修正 |
|-------|------|---------|:-------:|
| `desperate` | 背水一战 | 保级生死、总比分落后、末轮定生死 | **+0.30** |
| `high` | 战意高涨 | 争冠、欧战资格、德比、复仇、新帅首秀 | **+0.15** |
| `normal` | 正常 | 默认 | 0 |
| `low` | 战意偏低 | 已达标、保级无忧、双线保留 | **-0.15** |
| `dead_rubber` | 无欲无求/放弃 | 赛季末无意义、全力备战更关键赛事 | **-0.30** |

**防重复计分**：同一战意来源只用一条通道。德比氛围已用 `derby_boost=true` 时，不要再把该队 `fighting_spirit` 设为 `high`；保级/争冠/副班长情境已被 `classify_match()` 自动加成，默认写 `normal` 或省略，仅在有额外明确依据（复仇、新帅效应、摆烂轮换等）时显式标注。

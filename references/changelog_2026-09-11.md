# 全局模型改进记录 2026-09-11

触发事件：2026-09-11 七场复盘（方向命中 3/7 = 42.9%，比分 0/7）。

| 场次 | 预测 | 实际 | 结果 |
|---|---|---|---|
| 赫根 vs 米亚尔比 | 赫根胜 65.8% / 2-0 | 1-1 | 方向错，平局不足 |
| 阿尔克马 vs 威廉二世 | 阿尔克马胜 62.5% / 2-1 | 1-1 | 方向错，平局不足 |
| 柏林联合 vs 沙尔克04 | 柏林联合胜 57.8% / 2-0 | 1-3 | 方向错，后防伤停低估 |
| 威尼斯 vs 佛罗伦萨 | 佛罗伦萨胜 52.3% / 0-1 | 2-4 | 方向对，总进球严重低估 |
| 雷恩 vs 马赛 | 雷恩胜 38.8% / 2-1 | 1-0 | 方向对，总进球高估 |
| 西汉姆 vs 雷克瑟姆 | 西汉姆胜 52.4% / 2-1 | 6-0 | 方向对，级别差被旧快照压住 |
| 塞维利亚 vs 巴伦西亚 | 平局 34.6% / 1-1 | 1-0 | 方向错，平局保护用错方向 |

数据：实际总进球 22（均 3.14），主预测比分总进球 16（均 2.29），场均少估 0.86 球。预测分布集中在 1~3 球，实际分布为 1~6 球，属**方差不足**而非单纯低估。

## 改进1：条件平局保护（CONDITIONAL_DRAW_PROTECTION）

**问题**：赫根（近5个主场仅1胜）与阿尔克马（对手近6个客场不败）两场都应增平局，模型却给了 62~66% 的主胜；而塞维利亚对 8 人缺阵的瓦伦西亚却把平局推成第一方向，属相反错误。

**规则**：
- 触发：主队近 5 个主场 ≤1 胜，**或**客队近 6 个客场保持不败
- 否决：任一方伤停+停赛 ≥6 人时不再加平局
- 效果：平局 +5pp，从热门方向扣减
- 证据字段：`matches[].tactical.draw_gate = {home_last5_home_wins, away_last6_away_unbeaten}`

## 改进2：单边人员危机（UNILATERAL_ABSENCE_CRISIS）

**问题**：瓦伦西亚 8 人缺阵、塞维利亚 1-0 取胜，模型却因近均衡平局保护把平局列为第一方向。

**规则**：
- 触发：一方缺员 ≥6 人且另一方 ≤2 人
- 效果：缺员方胜率 -6pp 并**转给健康方**（不转给平局），平局加成被禁用；健康方 xG +0.25；3-0/4-0 档（净胜≥3且缺员方≤1球）比分权重 ×1.25
- 证据字段：`teams.<code>.injury_count` / `absence_count` / `suspension_count`

## 改进3：总进球方差修正（TOTAL_GOALS_VARIANCE）

**问题**：西汉姆 6-0、威尼斯 2-4 被压成 2-1、0-1；雷恩 1-0、塞维利亚 1-0 又被高估。模型总进球分布过窄。

**规则**：
- A 漏勺局：双方近期场均失球均 ≥1.5 → 总 xG 每队 +0.30~0.50（合计 +0.6~1.0），4 球以上比分权重 ×1.15
- B 稳健局：Elo差 <50 且双方场均失球均 <1.5 → 总 xG 压缩至约 2.60，1-0/0-1/1-1 权重 ×1.15，不默认 2-1
- 证据字段：`teams.<code>.conceded_per_game` 或 `matches[].recent_defense`

## 改进4：快照时效检查（SNAPSHOT_FRESHNESS_CHECK）

**问题**：英冠快照西汉姆 1504 / 雷克瑟姆 1372 已过期，而 MCP 近期状态显示西汉姆 5 场 12 球，模型仍给出 2-1，实际 6-0。

**规则**：
- 读取 `references/<league>/teams.json` 的 `_meta.updated_at` / `_meta.updated`
- 落后比赛日期超过 21 天时，用 `intel.teams.<code>.form_elo_adjust` 做临时 Elo 修正，上限 ±25
- 修正仅在内存生效，**不写回快照**；若过期但未提供修正，输出 ⚠️ 提示

## 适用范围

四条规则只对**英超、西甲、德甲、意甲、法甲、欧冠、英冠**生效（`leagues` 字段），由 `_rule_applies()` 统一门控；其他联赛传入字段也不会触发。

## 回归验证

| 项目 | 结果 |
|---|---|
| 西汉姆 vs 雷克瑟姆回放 | 主胜 52.4% → **62.6%**，xG 2.21-1.24 → 2.49-0.82，首选比分 2-1 → **2-0**，Top3 出现 3-0 |
| 塞维利亚 vs 巴伦西亚回放 | 主胜 33.8% → **47.2%**，平局 34.6% → 33.9%，方向由平局纠正为**主胜**（实际 1-0） |
| 条件平局门控（英冠） | 平局 41.7%，输出「条件平局保护(主队近5个主场仅1胜，平局+5pp)」 |
| 稳健局压缩（Elo差20） | 总 xG 压至 2.60，Top3 = 1-1 / 1-0 / 0-1，`2-1` 退出前三 |
| 非优先联赛门控 | 瑞超同证据不生效（符合设计） |

## 改进1：条件平局保护（CONDITIONAL_DRAW_PROTECTION）

**问题**：赫根（近5个主场仅1胜）与阿尔克马（对手近6个客场不败）两场都应增平局，模型却给了 62~66% 的主胜；而塞维利亚对 8 人缺阵的瓦伦西亚却把平局推成第一方向，属相反错误。

**规则**：
- 触发：主队近 5 个主场 ≤1 胜，**或**客队近 6 个客场保持不败
- 否决：任一方伤停+停赛 ≥6 人时不再加平局
- 效果：平局 +5pp，从热门方向扣减
- 证据字段：`matches[].tactical.draw_gate = {home_last5_home_wins, away_last6_away_unbeaten}`

## 改进2：单边人员危机（UNILATERAL_ABSENCE_CRISIS）

**问题**：瓦伦西亚 8 人缺阵、塞维利亚 1-0 取胜，模型却因近均衡平局保护把平局列为第一方向。

**规则**：
- 触发：一方缺员 ≥6 人且另一方 ≤2 人
- 效果：缺员方胜率 -6pp 并**转给健康方**（不转给平局），平局加成被禁用；健康方 xG +0.25；3-0/4-0 档（净胜≥3且缺员方≤1球）比分权重 ×1.25
- 证据字段：`teams.<code>.injury_count` / `absence_count` / `suspension_count`

## 改进3：总进球方差修正（TOTAL_GOALS_VARIANCE）

**问题**：西汉姆 6-0、威尼斯 2-4 被压成 2-1、0-1；雷恩 1-0、塞维利亚 1-0 又被高估。模型总进球分布过窄。

**规则**：
- A 漏勺局：双方近期场均失球均 ≥1.5 → 总 xG 每队 +0.30~0.50（合计 +0.6~1.0），4 球以上比分权重 ×1.15
- B 稳健局：Elo差 <50 且双方场均失球均 <1.5 → 总 xG 压缩至约 2.60，1-0/0-1/1-1 权重 ×1.15，不默认 2-1
- 证据字段：`teams.<code>.conceded_per_game` 或 `matches[].recent_defense`

## 改进4：快照时效检查（SNAPSHOT_FRESHNESS_CHECK）

**问题**：英冠快照西汉姆 1504 / 雷克瑟姆 1372 已过期，而 MCP 近期状态显示西汉姆 5 场 12 球，模型仍给出 2-1，实际 6-0。

**规则**：
- 读取 `references/<league>/teams.json` 的 `_meta.updated_at` / `_meta.updated`
- 落后比赛日期超过 21 天时，用 `intel.teams.<code>.form_elo_adjust` 做临时 Elo 修正，上限 ±25
- 修正仅在内存生效，**不写回快照**；若过期但未提供修正，输出 ⚠️ 提示

## 适用范围

四条规则只对**英超、西甲、德甲、意甲、法甲、欧冠、英冠**生效（`leagues` 字段），由 `_rule_applies()` 统一门控；其他联赛传入字段也不会触发。

> **已升级**：本节的联赛白名单在当天后续迭代中被**通用规则引擎**取代，四条规则现默认对所有联赛生效，改用「证据门槛 + 强度缩放 + 硬上限守卫」约束。详见下方「改进5」。

## 改进5：通用规则引擎（rule_engine.py）

**问题**：白名单方案等于把问题从"模型漏判"换成"规则不适用"——瑞超、荷甲、日职、韩职、挪超等联赛遇到同样的平局低估、方差不足问题时完全得不到修正，而它们的数据质量并不比英冠差。

**方案**：新增独立模块 `scripts/rule_engine.py`，让规则本身声明约束，由引擎统一裁决：

| 机制 | 说明 |
|---|---|
| 通用性 | `leagues` 可为 `"all"` / 省略 / 白名单；四条规则全部改为 `"all"` |
| 证据门槛 | 规则声明 `requires`（`draw_gate` / `absence_counts` / `conceded` / `form_elo_adjust`）；完整度低于 `min_evidence_ratio` 直接不触发 |
| 强度缩放 | 效果 = `strength` × 联赛成熟度 × 证据完整度 |
| 联赛成熟度 | 已匹配赛果样本 ≥15 → 1.0；不足 → 0.7（`thin_sample_league_strength`），样本累积后自动提升；可用 `league_strength_overrides` 手动覆盖 |
| 硬上限守卫 | 总 xG 位移 ≤0.60；单边概率转移 ≤0.10；平局锁定 [0.08, 0.45]；最小单边概率 0.02；最终重新归一化 |

**为什么这样能安全地放开到全联赛**：证据缺失 → 不触发；样本不足 → 只出一半力；多条规则共振 → 总位移被硬顶。三条防线叠加后，最坏情况也不会把概率推变形。

**可审计性**：预测输出新增 `model_inputs.rule_engine`：

```json
{"league_strength": 0.7, "prob_base": [...], "prob_final": [...],
 "prob_transfer": [...], "xg_base": [...], "xg_final": [...],
 "xg_shift_total": 0.6, "crisis": "QPR"}
```

## 回归验证（引擎版）

| 项目 | 结果 |
|---|---|
| 非优先联赛通用性 | 瑞超/荷甲/日职/挪超/韩职 **全部触发**（旧版全部不触发） |
| 联赛强度缩放 | 西甲(17样本)=1.00；英冠(10)/日职(7)/韩职(10)=0.70 |
| 强度体现在数值上 | 临时Elo ±20 → ±14；缺员罚分 -6pp → -4pp；xG +0.25 → +0.17；比分 1.15x → 1.10x |
| xG 总位移封顶 | 极端证据下正好封在 **+0.600**（上限0.60） |
| 概率层位移封顶 | `[+0.042, 0.0, -0.042]`，在 ±0.10 内 |
| 平局上下界 | 0.213 ∈ [0.08, 0.45]，概率合计 1.000000 |
| 证据缺失 | 新规则命中 **0** 条，不误伤 |

## 后续观察

- 四条规则现在全联赛生效，但样本不足的联赛只出一半力；需累计样本让强度自动升到 1.0
- 平局门控与缺员危机依赖 Agent 主动提供结构化情报，预测流程中应固定执行「先查快照时效 → 再取 MCP 近期状态 → 填 `form_elo_adjust` / `conceded_per_game` / `draw_gate` / `injury_count`」
- 若「大球桶」命中率下降，优先回调 `leaky_total_boost_per_side`
- 若发现某联赛规则效果明显异常，可用 `rule_engine.league_strength_overrides` 单独降权，而不必改代码
